FOLDER INI UNTUK FOTO 360° VIRTUAL TOUR
========================================

Cara pakai:
1. Ambil foto 360° (lihat panduan di README.md bagian "Virtual Tour 360°").
2. Pastikan format foto adalah PANORAMA EQUIRECTANGULAR dengan rasio lebar:tinggi = 2:1
   (contoh: 4000 x 2000 piksel). Ini format standar yang otomatis dihasilkan oleh
   aplikasi Google Street View, Insta360, Ricoh Theta, dll.
3. Simpan file foto ke folder ini, misalnya:
   - halaman-depan.jpg
   - ruang-kelas.jpg
   - perpustakaan.jpg
   - aula.jpg
4. Buka file data/tour.json di folder utama, lalu tambahkan satu entri per foto
   mengikuti contoh yang sudah ada di sana.
5. Simpan, upload ke GitHub — Virtual Tour akan otomatis aktif di website.

Tidak perlu compress manual — cukup pastikan ukuran file di bawah 5 MB per foto
supaya loading tetap cepat (bisa dikecilkan lewat situs kompres gambar gratis
seperti squoosh.app atau tinypng.com jika perlu).
